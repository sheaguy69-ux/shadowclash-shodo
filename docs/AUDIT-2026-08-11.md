## THE LESSON THIS AUDIT KEEPS TEACHING

Every existing harness measured whether a move **FIRES**. All 180 fire. Meanwhile one move
drew the source board's caption text for months, two drew a frozen cell for 900ms, and a
guard never reacted. **Firing is not working.** The three checks added here — STATIC,
frame hygiene, and the mechanics invariants — measure the difference.

And a checker that cries wolf hides the wolf: `check_moves.py` sat at 152 failures, 151 of
them a regex blind spot (`_wired()` stripped trailing digits but not the `_` before them,
so every Form 2 cell read dark). The one real failure was invisible underneath. It is now
152 → 0, and every new detector ships with its false positives listed and reasoned.
